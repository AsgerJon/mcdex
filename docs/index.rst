mcdex
=====

A typed, version-agnostic catalogue of Minecraft for Python: every
item, block and entity with one identity across all versions, carrying
what it is, what it does and when it arrived. Targets Python 3.14 and
3.15. Not affiliated with Mojang or Microsoft.

Installation
------------

.. code-block:: bash

   pip install mcdex
